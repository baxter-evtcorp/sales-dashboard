Definitions and privacy

Only the two current log tabs are analyzed. Summary, Calcs, lookup, instruction, definition, and historical tabs are excluded. Template rows and summary totals are excluded. Counts represent valid log rows, not unique deals.

The default combined view adds hardware/software and PS exactly once per log row. PS uses a complete actual financial set when available (including genuine zero values); otherwise a complete estimate pair is used and labeled. Partial or invalid actuals trigger a source finding and use the estimate pair, without mixing actual revenue with estimated GP. If neither set is complete, the row is excluded with a finding. PS actual PROFIT is used as its GP contribution because the source has no actual GROSS PROFIT column. Hardware/software uses SOLD AT and GROSS PROFIT. PS estimates use SOLD AT E and GROSS PROFIT E. PS actuals use SOLD AT and PROFIT from the actuals section, only where all actual financial fields are present. The date basis is Date Closed, not invoice or payment date. No invoiced revenue, pipeline probability, or full-year completeness is inferred.

Gross margin uses total gross profit divided by total sales. PS actual profit margin uses total actual PROFIT divided by actual SOLD AT. A zero sales denominator displays no margin. The $ symbol follows the workbook; currency is not independently verified.

Simple same-row arithmetic formulas are recalculated without executing spreadsheet code. Unsupported formulas, missing financial inputs, invalid dates and schema changes are reported. Text dates use MM/DD/YY or ISO YYYY-MM-DD. Source changes require choosing the workbook again.

The file is read only in browser memory. No uploads, remote scripts, telemetry, browser storage, or automatic exports are used. Clear workbook or close this page to remove the current session’s data. On a hosted site, the host still receives ordinary page requests; workbook data is not sent with them.
